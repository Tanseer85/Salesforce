Governor Limits are restrictions Salesforce puts on how much CPU, database, memory, and other resources your Apex code can consume in a single transaction.
The reason is simple: Salesforce is a multi-tenant platform — many customers share the same infrastructure. One customer's code shouldn't consume all the resources.
Resource / Operation,                           Synchronous Limit,                      Asynchronous Limit
Total SOQL Queries,                                  100,                                         200
Total Records Retrieved by SOQL,"                   50,000                                       50,000
Total SOSL (Text Search) Queries,                    20                                           20
"Total DML Statements (insert, update, etc.)",       150                                          150
Total Records Processed via DML,                     10,000                                     10,000
Maximum CPU Time                                     10,000 ms (10 sec)                     60,000 ms (60 sec)
Maximum Heap Size (RAM)                              6 MB                                         12 MB
Callouts (HTTP requests or web services)            100                                            100
Maximum Callout Timeout (Cumulative)                120 seconds                                120 seconds

Example: 
for (Contact c : contacts) {
    List<Account> accounts = [
        SELECT Id, Name
        FROM Account
        WHERE Id = :c.AccountId
    ];
}

If you have 150 contacts, you could execute 150 SOQL queries and exceed the 100-query limit.

You may get:

System.LimitException:
Too many SOQL queries: 

================================================
Programmatic Limit Monitoring
Apex provides the Limits system class to inspect current usage and remaining headroom within a transaction:
System.debug('SOQL Queries Used: ' + Limits.getQueries());
System.debug('SOQL Queries Max: ' + Limits.getLimitQueries());
System.debug('Remaining CPU Time: ' + (Limits.getLimitCpuTime() - Limits.getCpuTime()) + ' ms');
