A custom exception is a user-defined Apex exception created by extending the Exception class. We use it to represent and handle specific business or application errors.


Instead of using a generic Exception, you can create an exception with a meaningful name.

public class InsufficientBalanceException extends Exception {
}

use:
public static void withdraw(Decimal amount, Decimal balance) {

    if (amount > balance) {
        throw new InsufficientBalanceException(
            'Insufficient balance'
        );
    }
}

Hanlde it:
try {
    withdraw(1000, 500);
}
catch (InsufficientBalanceException e) {
    System.debug(e.getMessage());
}
